# Polarization-Guided Reflection Removal

这是一个面向课题探索的研究仓库，目标是研究：

> 如何让偏振信息可靠、可解释地帮助RGB图像去除玻璃反射，并进一步验证
> RGB恢复结果能否反过来纠正偏振表示，形成真正有用的双向纠偏。

当前工作使用PolaRGB数据，参考PPFT的多模态融合思路和PIDSR的显式偏振量、
互补任务与循环结构，但不会直接照搬二者。

## 当前结论

- PolaRGB极小规模数据与接口审计通过。
- PIDSR完成结构理解型最小复现。
- `E0 RGB-only`训练链路有效，但只是较弱基线。
- `E1 Polar→RGB`证明网络确实使用了偏振信息，是当前最强开发基线。
- `E2 RGB→Polar→RGB`、冻结E1后的R2P head-only诊断，以及加入候选偏振GT
  监督的R2P诊断，均未产生稳定RGB去反射增益。
- 这不等于所有双向纠偏都无效。现有证据只否定已经测试的FiLM式潜特征
  反馈和当前有监督残差实现。

当前最关键的问题已经收窄为：

> 如果保持观测强度不变，只把实测偏振状态`q/u`替换为更准确的候选GT
> `q/u`，一个参数匹配的新任务接口能否改善RGB去反射？

下一项实验是state-only polar oracle。它先检验“更准确偏振状态是否存在
下游任务价值上限”，再决定是否值得继续实现RGB→Polar和双向纠偏。

## 开发期结果快照

下表来自固定开发测试场景，已经多次用于路线决策，不能视为最终独立测试。

| 模型 | PSNR↑ | SSIM↑ | LPIPS↓ | 解释 |
|---|---:|---:|---:|---|
| E0 RGB-only | 19.759 | 0.833 | 0.154 | RGB基线 |
| E1 Polar→RGB | **20.286** | **0.843** | **0.149** | 当前最强开发基线 |
| E2 RGB→Polar→RGB | 19.378 | 0.835 | 0.155 | 当前双向实现失败 |

E2相对E1下降约`0.908 dB`。后续两个seed的有监督R2P诊断中，
R2P-on相对off的PSNR分别约为`-0.047 dB`和`-0.048 dB`，说明偏振恢复
指标改善没有自动转化为RGB去反射能力。

## 仓库边界

本仓库是精简研究快照，不包含：

- PolaRGB数据；
- 模型权重与checkpoint；
- 服务器路径、环境日志和验收压缩包；
- 大量逐轮任务文档；
- 尚未形成稳定实现的实验代码。

现阶段重点是形成可证伪、可归因的研究问题，而不是提供完整训练产品。
