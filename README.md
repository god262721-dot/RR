
# Polarization-Guided Reflection Removal

这是一个面向课题探索的研究快照，研究目标是：

> 如何将与RGB图像配对的偏振观测，转化为稳定、可解释且可验证的反射去除增益。

项目使用PolaRGB数据开展开发期验证，并参考偏振反射去除、跨模态融合和显式
Stokes建模相关工作。当前重点不是堆叠一个完整网络，而是通过可归因对照逐步
判断研究问题是否成立。

最后更新：2026-07-27。

## 当前核心判断

现有证据要求区分三个问题：

1. **偏振是否包含RGB缺少的增量信息；**
2. **中间偏振表示或预测是否更准确；**
3. **RGB恢复网络能否通过当前接口有效利用这些信息。**

它们并不等价。当前最稳妥的结论是：

> 正确配对的偏振在开发集上具有可检测的增量价值；但更准确的偏振状态、更多
> 偏振通道或普通自适应门控，都没有自动带来稳定的RGB恢复增益。

因此，“RGB–Polar双向纠偏”仍只能作为待验证候选机制，不能作为已经成立的
项目主线或创新结论。

## 四阶段证据链

### 1. 偏振是否有用

- `E0 RGB-only`建立训练与评估基线。
- `E1 Polar→RGB`只增加单向偏振输入。
- E1的correct偏振明显优于zero和shuffled，说明模型确实依赖正确配对偏振。

### 2. 简单双向反馈是否更好

- `E2 RGB→Polar→RGB`在E1上增加FiLM式R2P反馈头。
- E2-large相对E1-large下降约`0.908 dB`。
- 该结果否定当前实现，不足以否定所有双向结构。

### 3. 失败是否只因偏振预测不准

- `TP09`冻结E1、仅训练R2P头，双seed未通过收益门。
- `TP10`加入候选偏振GT监督；偏振重建误差下降，但RGB PSNR仍退化。
- `TP11`直接提供GT偏振状态；`state_gt−pobs`仅`+0.0031 dB`，
  `combined−pobs`仅`+0.0186 dB`，均未达到预注册的`+0.05 dB`门槛。

这些结果支持“偏振准确性与下游任务效用之间存在接口错配”这一综合解释，
但尚未确定唯一因果机制。

### 4. 更强表示和融合是否解决问题

`TP18`在固定E1输出后进行了`表示 × 融合`的2×2 pilot：

| Run | 偏振表示 | 融合 | PSNR |
|---|---|---|---:|
| R0 | zero | adaptive | 21.3189 |
| R1 | `P0/q/u` | concat | 21.5557 |
| R2 | raw4+Stokes | concat | 21.5753 |
| R3 | `P0/q/u` | adaptive | **21.6314** |
| R4 | raw4+Stokes | adaptive | 21.5386 |

- R4相对R0为`+0.2198 dB`、8/12场景胜，说明二阶段存在配对偏振弱信号；
- 但其95% bootstrap区间跨0，且4/12场景退化；
- raw4+Stokes的平均表示主效应为负；
- adaptive的PSNR平均主效应仅`+0.0195 dB`、5/12场景胜；
- R3数值最好，但属于事后候选，不能直接作为最终模型。

## 关键开发指标

| 模型 | PSNR↑ | SSIM↑ | LPIPS↓ | 解释 |
|---|---:|---:|---:|---|
| E0-large | 19.759 | 0.833 | 0.154 | RGB-only开发基线 |
| E1-large | **20.286** | **0.843** | **0.149** | 单向偏振开发基线 |
| E2-large | 19.378 | 0.835 | 0.155 | 当前双向实现失败 |

这些结果来自已反复参与路线选择的固定开发场景，不能视为最终独立测试结果。

## 当前下一步

下一项建议实验不是继续训练新R2P或confidence模块，而是：

> 在现有R3 consumer上进行无需训练的full-Stokes oracle响应曲线。

将观测Stokes与候选GT Stokes按5个预注册系数插值，检查RGB输出是否对理想
Stokes校正产生稳定正响应。只有该consumer通过后，才训练任务对齐的
Stokes residual producer；只有producer平均有效但存在局部退化时，才研究
校准可靠性。
