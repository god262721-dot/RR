# 证据、限制与禁止外推

## 可以说

- PolaRGB本地接口已完成极小规模审计。
- E1的correct偏振优于zero/shuffled，模型确实使用偏振。
- E1-large是当前最强开发基线。
- 当前FiLM式R2P在联合训练、head-only训练和候选偏振GT监督三种条件下，
  都没有产生稳定RGB去反射增益。
- TP10证明偏振辅助任务可学习，但没有证明R2P反馈对RGB有用。

## 不能说

- “已经证明双向纠偏无效。”
- “偏振GT没有用。”
- “偏振预测越准，去反射一定越好。”
- “E1已经在独立测试集上普遍优于E0。”
- “置信度一定能修复当前R2P。”
- “PPFT或PIDSR已经提供了本项目的完整解决方案。”

## 已知实现风险

1. 早期训练Dataset持有内部RandomState，同时使用多个worker，可能产生相关
   裁剪；相对对照仍可参考，但严格复现性和数据增强多样性受限。
2. 早期运行启用了非严格确定性设置。
3. TP10在clamp后的输出上计算偏振损失，越界像素可能出现饱和梯度。
4. TP09/TP10曾把LPIPS胜场方向统一按“差值大于零”统计；正式准入没有依赖
   该字段，核心结论不变。
5. 开发测试场景已经被多次用于路线决策。

## 已作废设计

旧显式Stokes V1先做单位圆硬投影：

\[
(\hat q,\hat u)
=\frac{(\tilde q,\tilde u)}
{\max(1,\sqrt{\tilde q^2+\tilde u^2})},
\]

再计算：

\[
L_{\mathrm{phys}}=\max(0,\hat q^2+\hat u^2-1).
\]

投影已经保证平方和不超过1，因此该损失恒为零。该方案从未执行，历史实验
结果不受影响，但后续不得复用。

## 统计解释

- 现有bootstrap主要对场景做配对重采样，只描述当前场景的不确定性。
- 单seed模型比较不覆盖训练随机性。
- TP09/TP10的双seed提高了失败结论可信度，但仍不是最终论文级统计。
- 后续checkpoint应按scene-macro验证指标选择，避免帧数更多的场景权重过大。
