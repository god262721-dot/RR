必要实验判断研究问题是否成立。

## 当前路线

暂时保留“双向纠偏”作为待证伪假设，但不继续扩展旧R2P实现。

当前先执行state-only polar oracle，判断在保持强度信息不变时，更准确
`q/u`是否存在下游任务价值上限：

```text
Pobs → E1 → T1
             │
             ├─ 参数匹配任务适配器 + Pobs
             └─ 参数匹配任务适配器 + P0obs/qgt/ugt
```

只有oracle通过，才进入显式Stokes纠正设计。若oracle失败，路线切换为：

```text
单向 Polar→RGB
  ├─ 显式融合
  ├─ 偏振可靠性
  └─ 后续再研究像素级任务相关注入
```
